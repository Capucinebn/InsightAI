# InsightAI

Plateforme d'analyse de texte propulsée par l'IA Gemini de Google.

## Fonctionnalités

**Analyse de sentiment** — Détecte le ton émotionnel d'un texte, identifie les émotions et génère des insights business actionnables avec un score de 0 à 10.

**Résumeur intelligent** — Condense n'importe quel texte long en points clés structurés et actionnables.

**Générateur de personas** — Crée des fiches personas clients détaillées à partir d'une description produit ou service.

## Technologies

- Python / Flask
- Google Gemini API
- HTML / CSS / JavaScript
- python-dotenv

## Installation

1. Clone le repo
   git clone https://github.com/Capucinebn/InsightAI.git
   cd InsightAI

2. Installe les dépendances
   pip install -r requirements.txt

3. Crée un fichier .env
   GEMINI_API_KEY=ta_clé_ici

4. Lance l'application
   python3 app.py

5. Ouvre http://127.0.0.1:5000 dans ton navigateur
